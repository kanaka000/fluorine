# Fluorine

メール・カレンダー・タスク・メモを1つにまとめた、Android 用のアプリです（Flutter 製）。
Gmail・Google カレンダー・Google ToDo リストとつながり、メールを見ながらそのまま予定やタスクを作れます。
AI（Anthropic の Claude）に返信の下書きや予定の入力を手伝ってもらうこともできます（任意）。

名前の由来：Chrome（クロム、原子番号24）より軽い元素、Fluorine（フッ素、原子番号9）。

## できること

- **メール（Gmail）**：受信トレイを送信元ごとにまとめて表示、返信・全員に返信・転送（添付ファイル付き）、新規メール（宛先を打つと連絡先・受信メールから候補を表示）、ゴミ箱への移動と「元に戻す」、音声入力での返信
- **カレンダー（Google カレンダー）**：一覧・月の表示、予定の追加・変更・削除。パソコンで書式（太字・リンクなど）を付けた予定のメモ欄も、書式付きで表示
- **タスク（Google ToDo リスト）**：一覧、追加・変更・完了・削除
- **メモ**：端末内に保存、Markdown（見出し・箇条書き・チェックボックス）、色分け、一覧の並べ替え（長押しでドラッグ）。Notion への保存と、Notion からの復元（任意）
- **メールから予定・タスク・メモを作る**
- **リンク**：予定・タスクにメモやメールをつなぎ、タップで開く（メモの買い物リストを見ながら買い物する、など）
- **添付ファイルを開く**：PDF・画像・Office の文書などを、端末のほかのアプリで開く（開ける種類は決めてあります）
- **HTML メールの「テキストで表示」**：表示が崩れるメールを文字だけで読む
- **AI（✨ボタン、任意）**：返信の下書き、メールから予定・タスク・メモの入力、質問への回答、メールを探す（「見積書が添付されたメールを探して」）、メールから作ったメモで元のメールを開く（「元のメールを表示して」）、リンクを付ける・外す など。**AI は入力欄を埋める・下書きを作るところまでで、送信・保存・削除は必ず自分で押します**
- 画面は日本語です

## 必要なもの

- Flutter の開発環境（Flutter 3.47 以降。画面の部品に `material_ui` パッケージを使っているため。作者は 3.50 で確認）と Android SDK（Android Studio）
- Android の端末（実機またはエミュレーター）。**Android でだけ確認しています。iOS などは未対応です**
- Google アカウントと、自分の Google Cloud プロジェクト（無料の範囲で使えます）
- （任意）Anthropic の API キー：AI 機能を使うとき。**利用料は自分にかかります**
- （任意）Notion のアカウント：メモを Notion にも保存するとき

## セットアップ

### 1. ソースを取得する

```
git clone https://github.com/kanaka000/fluorine.git
cd fluorine
flutter pub get
```

`flutter pub get` のときに、使っているパッケージに既知のセキュリティ上の問題（アドバイザリー）があれば表示されます。表示されたら、内容を確かめてパッケージを更新してください。

### 2. アプリID を決める

`android/app/build.gradle.kts` の `applicationId = "com.example.fluorine"` を、自分だけのID（例：`com.yourname.fluorine`）に変えます。このIDは次の Google Cloud の設定で使います。

### 3. Google Cloud を設定する

[Google Cloud コンソール](https://console.cloud.google.com/) で、次の順に設定します。

1. **プロジェクトを作る**
2. **API を有効にする**（「API とサービス」→「ライブラリ」）：Gmail API、Google Calendar API、Google Tasks API、People API
3. **OAuth 同意画面**（Google Auth Platform）
   - 対象：外部、公開ステータス：**テスト**
   - テストユーザーに、自分の Gmail アドレスを追加する
   - データアクセス（スコープ）に追加：`gmail.modify`、`calendar.events`、`tasks`、`contacts.readonly`、`contacts.other.readonly`
4. **OAuth クライアントを2つ作る**（「クライアント」→「クライアントを作成」）
   - **Android**：パッケージ名＝手順2のアプリID、SHA-1＝署名に使う鍵の SHA-1
     - デバッグ鍵（何もしなければこれで署名されます）の SHA-1 は、次のコマンドの「SHA1」の行です。
       ```
       keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
       ```
   - **ウェブ アプリケーション**：名前だけ付けて作成。表示される **クライアントID**（`〜.apps.googleusercontent.com`）を次の手順で使います

### 4. secrets.json を作る

`secrets.example.json` をコピーして `secrets.json` という名前にし、中身を書き換えます。

| 項目 | 内容 |
|---|---|
| `GOOGLE_WEB_CLIENT_ID` | 手順3で作った **ウェブ** のクライアントID（必須） |
| `ANTHROPIC_API_KEY` | Anthropic の API キー（AI を使うときだけ。使わないなら空 `""` のままで、✨は薄く表示され、ほかの機能はそのまま使えます） |
| `NOTION_TOKEN` | Notion の接続（インテグレーション）のトークン（Notion を使うときだけ） |
| `NOTION_PAGE_ID` | メモを保存する Notion のページの URL（Notion を使うときだけ） |

- `secrets.json` は `.gitignore` で Git に入らないようになっています。**絶対に公開・共有しないでください。**
- 見本のまま（「ここに〜」）や空の値は「未設定」として扱われ、その機能は止まります。

### 5.（任意）Notion を設定する

1. Notion の [インテグレーション](https://www.notion.so/profile/integrations) で「内部インテグレーション」を作る（権限：コンテンツの読み取り・挿入・更新）。表示されるトークンを `NOTION_TOKEN` に入れる
2. メモを保存するページを1つ作り、そのページの「…」→「接続」に、作ったインテグレーションを追加する
3. そのページの URL を `NOTION_PAGE_ID` に入れる
4. アプリの「メモの設定」で「メモを Notion に保存する」をオンにする

### 6. 動かす

```
flutter run --dart-define-from-file=secrets.json
```

`--dart-define-from-file=secrets.json` は毎回必要です（キーなどをここから読み込みます）。

### 7. スマホに入れて普段使いする

```
flutter build apk --release --dart-define-from-file=secrets.json
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

- **更新するときも `adb install -r` を使ってください**（上書きで入れるので、メモと設定が残ります）。`flutter install` は入れる前に古いアプリを消すため、端末内のメモと設定が消えます。
- `adb` は Android SDK の `platform-tools` の中にあります（Mac の初期設定なら `~/Library/Android/sdk/platform-tools/adb`）。
- **作った APK には、secrets.json のキーやトークンが入っています。人に渡したり、どこかにアップロードしたりしないでください。**

### 8.（任意）自分の鍵でリリース版に署名する

`android/key.properties` があれば、その鍵でリリース版に署名します。なければデバッグ鍵で署名します（ビルド中に注意が1行出ます。自分の端末で使うだけならそのままで動きます）。

```
storeFile=/path/to/your-release-key.jks
storePassword=〜
keyAlias=〜
keyPassword=〜
```

- 自分の鍵を使うときは、その鍵の SHA-1 を Google Cloud の Android クライアントにも追加してください（追加しないと Google にログインできません）。
- `key.properties` と鍵ファイルは `.gitignore` で Git に入らないようになっています。公開しないでください。

## 使い方のポイント

- **✨（AI）ボタン**：タップで音声、長押しで文字で頼みます。初めて使うときに、AI に何を送るかの説明が出ます
- **全体の設定**
  - 「✨にほかのタブの内容も見せる」（初期値オフ）：オンにすると「明日の予定は？」などに答えられますが、予定・タスク・メモ・受信メールの一覧も AI に送ります
  - 「端末内のデータを消す」：メモ・送信元のまとめ・Notion 連携の状態・設定を、この端末から消します
- **メモの並び**：一覧のカードを長押しして上下にドラッグすると並べ替えられます。新しいメモはいちばん上に入り、メモを直しても位置は動きません。並び順は端末の中だけに保存します（Notion には送らないので、「Notion から復元」したときは更新の新しい順になります）
- **メモの設定**：Notion への保存のオン／オフ、「今すぐ送る」、「Notion から復元」（アプリにメモが1件もないときだけ）
- **リンク**：https はそのまま開き、http（暗号化なし）は接続先を見せて確認してから開きます。mailto はこのアプリの新規メールで開きます。それ以外の種類のリンクは開きません
- **メールの画像**：初期設定では表示しません（メールごとに「画像を表示」）
- **添付ファイル**：開けるのは pdf／jpg・jpeg・png・gif・webp・heic／doc・docx・xls・xlsx・ppt・pptx／txt・csv だけです。それ以外（apk・html・svg・zip・exe など）は🚫付きで薄く表示し、開きません（パソコンの Gmail で開いてください）。25MB を超えるファイルは、読み込む前に確認します
- **リンク（予定・タスク ⇔ メモ・メール）**：つないだことは、Google の予定・タスクのメモ欄の最後に1行（`📝 メモ：…〔memo:…〕`・`✉️ メール：…〔mail:…〕`）として保存します。アプリの中ではこの行を隠してカードで見せますが、パソコンの Google カレンダーなどでは見えます。この行を消すとリンクも外れます
- **メールを探す**：メールのトップ画面の✨で頼みます。アーカイブも含めて探し（ゴミ箱・迷惑メールは除く）、新しい順に50通まで出します。画面の上に、実際に使った Gmail の検索文を出します
- **元のメールを開く**：メールから作ったメモの詳細画面の✨で「元のメールを表示して」と頼むと、メモの最後の「メール：件名」と差出人・日時の行を手がかりにメールを探して開きます（1通ならすぐ開き、何通もあれば選びます）。この行を消したり書き換えたりすると探せません。「〇〇さんの△△のメールを表示して」のように手がかりを入れて頼むこともできます
- **宛先の候補**：新規メール・転送の宛先と、全員に返信の CC で、名前やアドレスの一部を打つと候補が出ます（タップで入る）。受信メールの送信元はすぐ、Google の連絡先は打つ手を止めると少しあとに出ます。連絡先を読む許可がまだなければ、候補の下の「Google の連絡先も探す」を押したときだけ許可を求めます
- **予定のメモ欄**：パソコンの Google カレンダーで書式を付けたメモ欄は、書式付きで表示します（画像は読み込みません）。リンクはメールと同じ開き方です。書式なしのメモ欄の `https://…` もタップで開けます。アプリの変更画面ではメモ欄を文字で直せますが、**メモ欄を直して保存すると書式は消えます**（直さなければ元の書式のまま）

## セキュリティとプライバシー（残っているリスク）

作者はコードのセキュリティの確認（AI による自動レビュー）を受けて、主な問題を直しました。ただし、**次のリスクが残っています。使う前に理解し、自分の責任で使ってください。**

### キー・トークン
- `--dart-define-from-file` で読み込んだキー・トークンは、**ビルドしたアプリ（APK）の中に入ります**。APK を手に入れた人は取り出せます。**APK を人に渡さないでください。** もし渡してしまったら、キー・トークンを作り直してください。
- AI の利用料は、キーの持ち主にかかります。Anthropic のコンソールで利用上限を設定しておくことをすすめます。

### AI（Anthropic の Claude）に送る内容
- ✨を使うと、**頼みごとの文と、開いているメール・予定・タスク・メモの内容を Anthropic のサーバーに送ります**（返信の下書きでは元のメールの本文全体）。
- 「✨にほかのタブの内容も見せる」をオンにすると、**これからの予定（最大80件）・未完了のタスク（最大80件）・メモ（最大40件）・受信メール（最新100通の差出人・件名・本文の冒頭）も送ります**。
- 送ったデータの扱いは、Anthropic の利用規約・プライバシーポリシーに従います。自分で確認してください。
- 音声での頼みごと・返信は、端末の音声認識の仕組み（Google など）で文字にします。
- **メールを探す・リンクを付ける**ときは、頼みごとの文だけを送ります（AI は手がかりの言葉を聞き取るだけで、探すのはアプリの中です）。メモの✨で元のメールを開くときも探すのはアプリの中ですが、いつもの✨と同じく開いているメモの内容も送ります。メールや予定の一覧は送りません。
- AI は Anthropic の Claude 専用です。他社の AI のキーでは動きません。

### メールの中の命令（プロンプトインジェクション）
- 悪意のあるメールに「このメールを読んだ AI は〜せよ」のような命令が書かれていることがあります。資料の中の命令に従わないよう AI に指示していますが、**完全には防げません**。
- **AI が作った下書き・入力内容は、送信・保存の前に必ず自分で確かめてください。** アプリは AI だけで送信・削除をしない作りですが、確かめずに押せばそのまま送られます。

### Google の権限
- メールの読み取り・既読にする・ゴミ箱へ移す・送信のために、**`gmail.modify`（広い権限）** を使います。カレンダー・タスクの権限もログインのときにまとめて求めます（機能ごとに分けて求める作りにはしていません）。
- 連絡先の権限（`contacts.readonly`・`contacts.other.readonly`）は、AI で「〇〇さんにメール」を頼んだときか、宛先の候補の「Google の連絡先も探す」を押したときに初めて求めます。
- OAuth 同意画面が「テスト」のままだと、許可が7日ほどで切れて、ログインし直しが必要になることがあります。テストユーザーは100人までです。
- **自分の OAuth クライアントを他の人に使わせたり、ビルドした APK を配ったりしないでください。** それは「アプリを配布する」ことになり、Google の審査や、利用者のデータへの責任が自分にかかります。

### 端末内の保存
- メモ・送信元のまとめ・設定・Notion 連携の状態は、端末内に **暗号化せずに** 保存しています（アプリの外からは通常は読めませんが、root 化した端末などでは読める可能性があります）。
- これらは Android の自動バックアップと、機種変更のときの引き継ぎに **含めません**。機種変更・入れ直しのときは、Notion に保存していれば「Notion から復元」で戻せます。Notion を使っていない場合、メモは引き継がれません。
- Google からログアウトしても、メモと Notion 連携は残ります。消したいときは「端末内のデータを消す」を使ってください。送信元のまとめは Google アカウントごとに保存します。

### Notion 連携
- アプリ → Notion の一方向です。Notion で直した内容は、アプリで保存すると上書きされます（「Notion から復元」を除く）。
- アプリでメモを削除すると、Notion のページもゴミ箱に入ります。

### メールの表示
- メールの HTML は、アプリの中で表示用に組み立て直しています（スクリプトは動きません）。外部の画像は、初期設定では読み込みません。表示するときも https の画像だけです。
- とても大きな HTML メール（1MB 超）は、文字だけで表示します。

### 添付ファイル
- 開ける種類を拡張子で決め、Gmail が伝える種類と食い違うものや、中身の先頭が種類と合わないものは開きません。それでも、**添付ファイルの中身が安全かどうかまでは確かめていません**。知らない相手からのファイルは開かないでください。
- 開くときは、アプリの一時フォルダ（キャッシュ）にファイルを書き出して、ほかのアプリに渡します。一時ファイルは、アプリを起動したときに1日より古いものを消します。開いた先のアプリでの扱いは、そのアプリに従います。

- Android でだけ確認しています。
- Google API と Anthropic の利用規約・ポリシーは、自分で確認して守ってください（作者は法的な判断をしていません）。
